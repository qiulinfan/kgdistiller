# Citation discovery

The default quick path is defined in [resource-methods.md](resource-methods.md):
OpenAlex `cites:W_ID` returns incoming
citations; the target's references are outgoing. Any citing paper counts as a
successor, including a survey, comparison or background citation; method adoption
is not required. Use the prescribed bounded identity correction and one bounded source search.
Access errors end the provider; no retries or topic-wide searches.

A supplied Google Scholar Cited by view can be used when explicitly requested.
Do not invent cluster IDs or scrape all result pages. Connected Papers' core graph
is a similarity graph, not proof of citation or influence. Such visual tools are
optional exploration, not automatic fallback channels in the quick workflow.
